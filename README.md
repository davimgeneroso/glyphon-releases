# Glyphon · downloads

Instaladores do **Glyphon**, app de ditado por voz com IA para Windows e Android, de Davi Generoso.
Este repositório guarda só os arquivos de instalação; o código do app é privado.

**Página do app, com o passo a passo da instalação:** https://www.davigeneroso.com.br/glyphon

| Plataforma | Arquivo |
|---|---|
| Windows 10 ou 11 (64 bits) | [Glyphon-Windows-x64-setup.exe](https://github.com/davimgeneroso/glyphon-releases/releases/latest/download/Glyphon-Windows-x64-setup.exe) |
| Android 8 ou superior | [Glyphon-Android.apk](https://github.com/davimgeneroso/glyphon-releases/releases/latest/download/Glyphon-Android.apk) |

Cada versão traz a soma SHA-256 dos arquivos nas notas da release.
